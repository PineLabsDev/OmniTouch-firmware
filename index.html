OmniTouch

Touch control panel for Bambu Lab & Prusa printers · Guition JC8048W550 (ESP32-S3, 5″ 800×480)

Install or update

Latest …ESP32-S3 · 16 MB flash
This browser can't talk to USB serial devices. Use Chrome or Edge on a desktop computer.
Serial access needs HTTPS (or localhost).
  1. Connect the display to this computer with a USB-C data cable.
  2. Click Connect & install and pick the serial port (often USB-SERIAL CH340 or USB JTAG/serial).
  3. Choose Install. Keep “erase” ticked on the first install. It takes about a minute.
  4. When asked, enter your Wi-Fi — the display connects and shows its IP address.

Not detected? Hold BOOT, tap RST, release BOOT, then connect again. Already installed? Update over Wi-Fi from Settings → Display → Firmware on the screen, or from the device's web page.

Optional: SD-card config file

You can set everything on the touchscreen or at http://omnitouch.local. If you prefer, create omnitouch.json here, copy it to a FAT32 microSD card and insert it before power-up. It is imported once and then renamed.

Bambu: access code and serial are on the printer under Settings → Network/Device. For control, newer firmware needs LAN Only Mode + Developer Mode. Prusa: the PrusaLink password is on the printer under Settings → Network → PrusaLink.

Advanced flasher (your own files)

Flash any image at any address straight from the browser (esptool in JavaScript, Chrome/Edge). Useful for a test build, a tuned build, an older release or a full backup restore.

Not connected.
After USB flashing, unplug the display for 5 s and plug it back in — the USB reset can leave it in download mode (the screen then cycles test colours). The flash at 0x0 with the factory image keeps your settings unless “erase” is ticked.

Command line instead: esptool.py --chip esp32s3 --baud 921600 write_flash 0x0 omnitouch-factory.bin · files: omnitouch-factory.bin, omnitouch-ota.bin

Independent open-source project; not affiliated with Bambu Lab, Prusa Research or the original xtouch. Flashing replaces the firmware on the display only — your printers are not modified.
